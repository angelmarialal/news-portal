# Cloud-Based News Portal Web Application

## Project Overview
This project is a cloud-based News Portal Web Application developed using Flask and MySQL. The application allows users to register, login, publish news posts, upload images, edit posts, delete posts, and search news articles.

The project demonstrates DevSecOps concepts including Docker containerization, GitHub version control, AWS EC2 cloud deployment, and security implementation using bcrypt password hashing.



## Features
- User Registration and Login
- Secure Password Hashing using bcrypt
- Add, Edit, and Delete News Posts
- Image Upload Support
- Search Functionality
- Session Management
- Docker Deployment
- AWS EC2 Cloud Deployment



## Technologies Used
- Python Flask
- HTML/CSS
- MySQL
- Docker
- GitHub
- AWS EC2
- bcrypt
